Building geometry demonstration samples

The eight original samples were generated with Building Tools v1.0.13 and Blender 4.0.2. The ground boundary was capped. Building Tools is MIT licensed; see BUILDING-TOOLS-LICENSE.txt.
STL coordinates are metres, Z-up. GLB uses the glTF Y-up convention. These are synthetic building geometries, not real surveyed buildings or CFD results. Closed edge topology was checked; self-intersections and CFD mesh quality were not validated.
The browser workshop is an independent lightweight parametric geometry implementation; its exports are labelled browser-workshop-v1.
