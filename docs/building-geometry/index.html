WHY GEOMETRY COMES FIRST

可控的几何变化，让数据覆盖变得具体。建筑高度、长宽比例、凹口和屋顶，都是值得单独观察的设计变量。

关于生成方式与使用范围
源码样例：Building Tools v1.0.13 / Blender 4.0.2，已补齐接地底面。STL 使用米制、Z 向上；GLB 遵循 glTF 的 Y 向上约定。封闭边拓扑已检查，自交和 CFD 体网格未验收。
参数工坊：独立的浏览器轻量实现，提供矩形、圆形、L 形与 H 形体量。矩形支持三种屋顶，其余平面使用平屋顶；导出参数注明 browser-workshop-v1，不作为原 Blender 插件的执行结果。
