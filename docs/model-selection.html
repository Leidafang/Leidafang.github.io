方法研读 · 结构与选型

理解 DoMINO 与 GeoTransolver 的取舍

我的关注点逐渐从模型名称，转向它如何组织几何、工况与空间点信息，以及这些组织方式是否便于接入当前任务。

DoMINOGALE模型结构

DoMINO：几何编码与局部场查询

DoMINO 通过多尺度几何表示和局部查询组织场预测，CNN 是其中几何特征处理的重要组成部分。它也包含全局和多尺度信息，不能简化为只看局部。

理解这一结构时，我特别关注几何特征读取、位置编码与解码 stencil 的区别。查询附近的位置不意味着推理时需要读取附近点的真实压力或速度。

GeoTransolver：状态交互与共享条件

GeoTransolver 将点特征软聚合为较少的状态，通过状态之间以及状态与共享条件之间的交互来更新表示，再把更新传回空间点。它也使用局部几何邻域。

在本地核对的 GALE 实现中，self-attention 与 cross-attention 是并行分支，随后融合。学习到的状态不等于固定物理分区，堆叠层数也不等于物理时间步数。

当前选择的依据

我认为 GeoTransolver 的点特征与共享条件组织方式，更便于理解和接入当前场、控制条件等输入；已有任务实现也降低了继续沿这条路线研究的工程成本。这是针对当前项目的取舍。

结构偏好与公开案例可以提供启发，但不能替代公平实验。尚未在本项目同数据、同预算、同硬件条件下完成 DoMINO 与 GeoTransolver 的对照，因此这里不声称某一个已被证明更准、更快或更省数据。
