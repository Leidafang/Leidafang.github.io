PLATEAU building map viewer

Project PLATEAU / MLIT Japan. Source: Chiyoda-ku 2023 release, tile 53394509; https://www.geospatial.jp/ckan/dataset/plateau-13101-chiyoda-ku-2023 . Original policy: https://www.mlit.go.jp/plateau/site-policy/ . The releasing municipality and each building administrative code are retained separately.

Building footprints come from original geographic ground-surface polygons, with source roof-edge fallback identified when necessary. Existing source-polygon triangulation and zone-IX projection are reused; no smoothing, hole filling, or geometry repair. The original 30 project samples retain their native VTP. New building CityGML fragments are gzip-compressed and preserve original coordinates, IDs and attributes; textures and complete code lists remain with the original dataset. STL is a local-metric float32 preview. H=1 is isotropic scaling only. These are not accepted CFD volume meshes or training labels.

Leaflet 1.9.4: vendor/leaflet/LICENSE ; Three.js 0.180.0: vendor/THREE-LICENSE.txt . Street basemap: Geospatial Information Authority of Japan (GSI / 国土地理院), https://maps.gsi.go.jp/development/ichiran.html ; only tiles needed for an interactive viewport are requested, with normal browser caching.
