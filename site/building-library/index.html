数据范围、转换与质量说明
已收录模型来自 2026-10-14 的项目采样快照：3DBAG 为 Delft / Rotterdam 的局部窗口，PLATEAU 为千代田区发布的 2023 年度、53394509 瓦片。发布集城市与建筑属性中的行政区码分别保留，不能默认二者相同。使用现有源几何，保留庭院和原始体量，不在本页额外补洞、平滑或简化。
3DBAG 官方在线模式按 ID 请求 API，可选择接口返回的 LoD。LoD 表示几何表达细节，不是建筑类别；同一栋建筑在不同 LoD 下的屋顶和包围高度可能不同。PLATEAU 首版预览限已收录 30 栋；官方完整 CityGML 按城市 / 年度 / 瓦片发布，原瓦片约 128 MiB，不在打开本页时自动整包下载。
STL 使用本地米制、Z 向上坐标，预览为 float32；VTP 保留原几何库的数值精度。原始 CityJSON / CityGML 建筑片段保留原始坐标。H=1 STL 仅做等比缩放，不能视为已验证的 CFD 相似性。
55 栋源几何通过既有封闭边检查，3 栋仍需复核；自交和 CFD 体网格并未在本页验收。在线模型另显示浏览器三角化后的边检查，不替代正式几何质量报告。高度色彩只表示几何高度，不是 CFD 场。
